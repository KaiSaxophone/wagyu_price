# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？

- リモートリポジトリ
  - ネット上で複数人でソースコードを共有するリポジトリ。（GitHubなど）
- ローカルリポジトリ
  - 自身のPC上で個人でソースコードを配置するリポジトリ。

## プッシュとマージの違いは何でしょうか？

- プッシュ
  - ローカルリポジトリにコミットしたソースコードを、リモートリポジトリに反映させること。
- マージ
  - ブランチの編集内容を別のブランチに統合すること。

## コミットとプッシュの違い

- コミット
  - ステージングしたファイルの変更内容をローカルリポジトリに保存すること。
- プッシュ
  - コミットした変更内容をリモートリポジトリに反映させること

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？

- 変更した内容を一目見て分かるように、簡潔かつ具体的に書く。

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？

- ローカルでマージするフロー
  - ローカルでmainブランチまで反映させてからリモートリポジトリに反映する。
  - フローとしてはスムーズだが、レビューしてもらうタイミングがないので、思わぬ不具合が本番環境に実装される恐れがある。
- プルリクエストでマージするフロー
  - リモートリポジトリ上でmainリポジトリにmergeする。
  - mainブランチへのmerge前にリーダーの承認が必要になるので、レビューを挟むことで不具合を未然に防ぐことができる。

## コンフリクトを起こしてしまった場合、どう対処すべきですか？

- どちらの変更内容を反映するか確認し、どちらも反映が必要な場合は、ソースコードを書いた人と相談しつつ両方の変更を反映して再度マージする。
